One word, the word my ex would use to describe me. Not an insult, not a diagnosis: the verdict itself, in six letters. Almost the one. Almost enough. Almost.

> almost

## Run it

```sh
python3 main.py
```

It writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it.
